## 🏛 Classic Android vs Jetpack Compose

### Classic Android (XML days)

Developers commonly used:

* `GridLayout`
* `GridView`
* `RecyclerView` with `GridLayoutManager`

This required adapters, view holders, and a lot of boilerplate.

### Jetpack Compose ✨

Compose simplifies everything:

* No XML
* No adapters
* Declarative UI
* Built-in **lazy loading**

---

## ⚡ Why Lazy Grids?

Lazy components:

* Compose **only what’s visible**
* Improve performance & memory usage
* Scale smoothly for large datasets

Lazy Grids are perfect when:

* Items are visually similar
* All items have equal importance
* Screen space needs to be used efficiently

---

## 🧩 Grid Types Covered

### 🔹 LazyVerticalGrid

* Scrolls vertically
* Items arranged in columns
* Best for galleries, product lists, dashboards

### 🔹 LazyHorizontalGrid

* Scrolls horizontally
* Items arranged in rows
* Great for carousels and horizontal galleries
